# Online Shop – JavaScript Frameworks Course Assignment

An online shop built with Next.js (App Router), TypeScript and Tailwind CSS,
using the Noroff Online Shop API.

## Tech stack

- Next.js + React
- TypeScript (strict)
- Tailwind CSS
- Zustand (cart state)

## Getting started

npm install
npm run dev
